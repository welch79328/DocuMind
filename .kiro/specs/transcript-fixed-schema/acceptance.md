## 盤查結論（2026-10-14，三路唯讀盤查＋主持人抽查）
1. **DocuMind 沒有輸出規格。** 唯一定義過的固定輸出是 `.kiro/specs/document-ocr-enhancement/design.md:741-749` 的 7 鍵；25 欄、6 種清單沒有規格紀錄；`transcripts`（2.3.0）鍵名跟著謄本原文變動。
   兩個下游讀不同位置：jgb2 讀 `document_fields`（如 `total_area`），AIChatbot `transcript_mapper.py` 讀 `pages[].structured_data`（如 `area`）。
2. **jgb2 要的是一張固定表單。** 一般物件建物謄本表單 31 欄（土地標的清冊 3 筆時 43 欄），用於合約 PDF 與實價登錄。
   `TranscriptFieldMapper`（僅在 jgb2 `origin/preview`，`origin/master` 不存在——主持人以 `git cat-file` 確認，正對照 `HandoverPhotoAnalyzeService.php` 在 master 存在）
   只讀 `document_fields` 15 鍵；10 欄標「需人工」，其中 8 欄謄本上其實有印（層次 2–4 與各層面積 6 欄、共有部分權利範圍、持分面積〔可由前者推算〕）。
   他項權利、查封只在「偵測到」時帶「有」，偵測不到不敢說「無」（jgb2 commit `6c4da96339`）。
3. **官方格式支持固定欄位。** 各部欄位集合固定；變動只有：他項權利依權利種類不同、第一／二／三類遮罩值但欄位仍在、少數欄位可不印（地目等則 106/1/1 起停印；地上建物建號、前次移轉現值、主建物附表可勾選不印）。
   查封、信託、車位沒有獨立欄位，都在「其他登記事項」，新版前綴分類字樣（如「（限制登記事項）」「（一般註記事項）」），代碼表見 data.gov.tw 25099。
   來源與證據：盤查筆記 `scratchpad/official/notes.md`（汐止地所閱讀秘笈、旗山地所建物謄本導讀、ep.land 分級制與防偽手冊、土地登記規則 §24-1、§81、§83、§108-1、§109、§109-1、§130、§136）。
4. **現在改成本最低**：jgb2 謄本辨識尚未進 master；AIChatbot 的 LINE 路線客戶端尚未撰寫（line-bot-platform `docs/chatai-integration-readiness.md:19,37`）。

## 切片 TFS-1：固定輸出格式

### 輸出位置與外層結構
`document_fields.transcript_records`（僅 `document_type=transcript`）：一份檔案一個陣列，每張謄本一筆。外層鍵**一律存在**：
```jsonc
{
  "謄本": { … 固定鍵 … },
  "類型": "土地" | "建物",
  "標示部": { … 依類型的固定鍵 … } | null,          // 該部沒印 → null
  "所有權部": [ { … 固定鍵 … } ],                    // 沒印或 0 筆 → []
  "他項權利部": [ { … 固定鍵 … } ],
  "判定": { "他項權利": "有|未見|無法判定", "限制登記": "有|未見|無法判定", "信託": "有|未見|無法判定" },
  "部是否印出": { "標示部": bool, "所有權部": bool, "他項權利部": bool },
  "注意事項": [ "…" ],                                  // transcripts 的注意事項，原樣
  "其他欄位": [ { "部": "…", "標籤": "…", "值": "…", "原因": "…" } ]   // 固定清單外的標籤、或衍生拆不開的原文，一個不丟
}
```

### 固定鍵（依官方格式；括號內為 5 份樣本是否見過）
- **謄本**：`謄本種類`（原文）、`類別`（第一類／第二類／第三類）、`申請範圍`（括號內原文，如 建號全部、所有權個人全部）、`行政區`、`段`、`小段`、`編號`、`編號類型`（地號／建號）、
  `列印時間`、`頁數`、`查驗碼`、`查驗碼標籤`（原文「謄本檢查號」或「謄本種類碼」）、`查驗網址`、`資料管轄機關`、`謄本核發機關`、`頁首附註`（陣列，頁首沒有標籤的行原樣，例：「…由○○自行列印」「○○地政事務所 主 任 ○○○」「○○電謄字第○號」）
- **每個部另有 `附註`**（陣列，該部沒有標籤的說明句原樣，例：「本謄本僅係 所有權個人全部 節本…」）。
- **土地標示部**：`登記日期`、`登記原因`、`地目`、`等則`、`面積`、`使用分區`、`使用地類別`、`公告土地現值`、`公告土地現值年月`、`地上建物建號`、`其他登記事項`
- **建物標示部**：`登記日期`、`登記原因`、`建物門牌`、`建物坐落地號`（陣列 `{段小段, 編號}`）、`主要用途`、`主要建材`、`層數`、`總面積`、`層次`（陣列 `{層次, 面積}`）、
  `附屬建物`（陣列 `{用途, 面積}`）、`建築完成日期`、`共有部分`（陣列 `{坐落, 建號, 面積, 權利範圍, 其他登記事項}`）、`其他登記事項`
- **所有權部（每筆）**：`次序`、`登記次序`、`登記日期`、`登記原因`、`原因發生日期`、`所有權人`、`統一編號`、`出生日期`、`住址`、`管理者`（陣列 `{姓名, 統一編號, 住址}`）、
  `權利範圍`、`權狀字號`、`相關他項權利登記次序`（陣列）、`其他登記事項`；土地另有 `當期申報地價`、`當期申報地價年月`、`前次移轉現值`（陣列 `{年月, 金額, 歷次取得權利範圍}`）、`地價備註事項`
- **他項權利部（每筆）**：`次序`、`登記次序`、`權利種類`、`收件年期`、`字號`、`登記日期`、`登記原因`、`權利人`、`統一編號`、`住址`、`債權額比例`、`擔保債權總金額`、
  `擔保債權種類及範圍`、`擔保債權確定期日`、`存續期間`、`清償日期`、`利息(率)`、`遲延利息(率)`、`違約金`、`其他擔保範圍約定`、`債務人及債務額比例`、`權利標的`、
  `標的登記次序`（陣列）、`設定權利範圍`、`證明書字號`、`設定義務人`、`共同擔保地號`（陣列 `{段小段, 編號}`）、`共同擔保建號`（陣列 `{段小段, 編號}`）、`其他登記事項`
- **其他登記事項**（各部共用）：陣列 `{類別, 標籤, 內容}`——`類別` 是原文前綴分類（如「限制登記事項」，舊版沒有則 null）；`標籤` 是項目名（如 重測前、使用執照字號、因分割增加地號）。
- **`transcripts` 每一項的去處**（R2 對帳範圍）：5 份樣本見過的 104 種「部＋標籤」中，`頁首.頁次` → `謄本.頁數`（只留頁數，頁碼本身不另存）；`頁首.附註` → `謄本.頁首附註`；各部 `附註` → 該部 `附註`；
  `注意事項` → `注意事項`；`其他登記事項` 底下的子標籤（重測前、重劃前、因分割增加地號、建物平面圖冊頁數…）→ 該部 `其他登記事項[]` 的一項；其餘全部是固定鍵。
  **唯一排除**：`頁緣`（每頁頂格的地政事務所名、頁角 1–2 碼英數，頁面邊緣文字、非謄本內容；仍在 `transcripts`）。
  表中 5 份樣本沒見過的鍵（出生日期、管理者、地價備註事項、存續期間、附屬建物等）依官方文件列入，以合成樣本驗證。

### 衍生鍵的取值規則（依值的性質或官方版面，不寫欄位片語；拆不開 → 該鍵 null，原文進 `其他欄位` 並註明原因）
| 衍生鍵 | 來源 | 通用規則 | 依據 |
|---|---|---|---|
| `類別`、`申請範圍` | 頁首 `謄本種類` | 官方標題結構「(土地\|建物)登記第(一\|二\|三)類謄本（申請範圍）」：類別取「第○類」，申請範圍取括號內 | ep.land 防偽手冊、汐止閱讀秘笈樣本標題 |
| `行政區`、`段`、`小段` | 頁首 `地段` | 行政區＝開頭與**內政部全國鄉鎮市區名稱表**（資料檔，記資料集網址與版本）比對的最長相符名稱（「平鎮區」不會被切成「平鎮」）；沒有相符 → 行政區 null，整串視為段小段；其餘部分若以「小段」結尾：先去掉結尾的「小段」二字，剩下部分最後一個「段」字之前（含）為段，其後加回「小段」為小段（`仁愛段六小段` → 段 `仁愛段`、小段 `六小段`）；不以「小段」結尾 → 整段為段、小段 null | 官方標題「行政區＋段小段＋地號」；以全國名稱表取代「切到第一個區鄉鎮市」——後者遇平鎮區、前鎮區、新市區會切錯（第 2 輪審查） |
| `頁數` | 頁首 `頁次` | 該張謄本的頁數（`頁次` 的個數） | — |
| `列印時間` | 頁首 `列印時間` | 各頁相同 → 單值；不同 → 取第一頁，其餘進 `其他欄位` | — |
| `查驗碼`、`查驗網址` | 頁首 `謄本檢查號`／`謄本種類碼` 的值 | 查驗碼＝值開頭連續的英數字；查驗網址＝值中以 `http` 開頭到空白或中文為止的網址；`查驗碼標籤` 記原文標籤 | 值的性質（代碼為英數、網址為 URL） |
| `面積`、`總面積`、`層次[].面積`、金額類 | 值 | **先去掉值開頭的年月**（「(民國)?○年○月」，存入對應的年月鍵），再取剩下的唯一數字（去千分位）；剩下 0 個或 2 個以上數字 → null、原文進 `其他欄位`。例：`107年01月 94,400.0元/平方公尺` → 年月 `107年01月`、金額 94400.0 | 值的性質 |
| `層次[]`（`{層次, 面積}`）、`附屬建物[]`（`{用途, 面積}`） | 平行標籤 `層次`／`層次面積`、附屬建物的用途與面積標籤 | 兩個標籤各取值（單一字串視為 1 筆），依出現順序一對一配對；**筆數不同 → 該陣列輸出 []，兩邊原文進 `其他欄位`**（不猜配對） | 原文層次表為同一行並列（G6 表格續行） |
| `公告土地現值年月`、`當期申報地價年月`、`前次移轉現值[].年月` | `_前文` 或值開頭 | 數字前的「(民國)?○年○月」 | 值的性質 |
| `共有部分[].建號`、`共有部分[].面積` | `共有部分._值`（例：`仁愛段六小段02163-000建號 3,213.92平方公尺`） | 建號＝以「建號」結尾的「數字-數字」；面積＝接面積單位（平方公尺）的數字；段小段文字留在 `共有部分[].坐落` | 值的性質（編號格式、面積單位） |
| `建物坐落地號`、`共同擔保地號／建號` | 值 | 以空白切開；非數字開頭的片段是段小段，其後每個數字開頭的片段是一個編號，產生 `{段小段, 編號}`（段小段沿用到下一個段小段出現為止） | 值的性質 |
| `標的登記次序`、`相關他項權利登記次序` | 值 | 以空白切成陣列 | 值的性質 |
| `其他登記事項[]` 的 `類別` | 每一項 | 開頭為全形或半形括號包住、以「事項」結尾的片段 → 類別（去括號），其餘為內容；沒有 → null | 官方代碼 25099 類別前綴格式（如「（限制登記事項）」「（一般註記事項）」） |
| `其他登記事項[]` 的 `標籤` | 每一項 | 內容中第一個冒號前若是連續中文（不含數字）→ 標籤，冒號後為內容；否則標籤 null、整段為內容（例：「轉載自舊建簿4冊1頁」） | 與 G6 標籤定義一致（連續中文＋冒號），只是不要求冒號前有空白 |

### 值的規則
- **沒印 → null**；原文「(空白)」、「民國---年--月--日」→ null（與 25 欄一致）；陣列欄沒有就是 `[]`。原文仍保留在 `transcripts`。
- **面積、金額 → 數字**（`總面積: 403.21`、`擔保債權總金額: 93600000`、`公告土地現值: 860`）；單位固定（平方公尺；元；元／平方公尺），寫在 Schema 說明。讀不出數字 → null，原文進 `其他欄位`（`標籤` 加註「無法轉數字」）。
- **權利範圍**：沿用 2.1.1——「全部」或「分子分之分母」（`全部 1分之1` → `全部`）。
- **日期**：原文民國字串（`民國050年03月14日`），不轉西元（非目標）。
- **遮罩**：照原文（`黃**`、`A202*****6`）；JGB 依 `謄本.類別` 判斷是否遮罩。
- **判定**（JGB 拿來勾「有／無」，最容易誤導，規則寫死在文件）：
  - `他項權利`：該張他項權利部有筆 → 有；申請範圍包含他項權利部（全部、地號全部、建號全部、標示部及他項權利部、他項權利個人全部）而沒有筆 → 未見；其他申請範圍 → 無法判定。
  - `限制登記`、`信託`：比對範圍是該張標示部與所有權部每一項 `其他登記事項` 的 `類別`、`標籤`、`內容`，以及所有權部的 `登記原因`；比對詞全部來自代碼表檔（見下），**依表別比對對象不同**：
    | 比對對象 | 代碼表（data.gov.tw，115/08 版） | 限制登記 | 信託 |
    |---|---|---|---|
    | `其他登記事項[].類別` | 25099 其他登記事項類別 | 代碼 99「（限制登記事項）」 | — |
    | `其他登記事項[].標籤`（**整串相等**） | 25099 其他登記事項類別 | GZ「預告登記請求權人」 | GJ「委託人」 |
    | `其他登記事項[]` 整項原文（**整串相等**，去空白與全半形差異） | 25099 其他登記事項類別 | — | GH「信託財產，信託內容詳信託專簿」 |
    | 所有權部 `登記原因`（**整串相等**） | 25100 登記原因 | 33 查封、49 假扣押、50 假處分、51 破產登記、52 禁止處分、58 預告登記、AU 未登記建物查封 | CU 信託、CX 信託歸屬、CY 信託取得 |
    **一律整串相等，不做「包含」比對**：25099 自己的限制性註記句（H2、9R 含「預告登記」，9O 含「信託」）與「塗銷查封」「塗銷信託」都不會因此被判成有。自由文字（舊版沒有類別的註記）不拿來判「有」，只會讓結果變成無法判定（見下）。
    輸出：
    - 比對到任一項 → **有**。
    - 沒比對到，且同時符合：申請範圍為全部類（全部、地號全部、建號全部）、該張每一項 `其他登記事項` 不是原文空白就是有 `類別` → **未見**。
    - 其餘 → **無法判定**。特別是：只要有任何一項 `其他登記事項` `類別` 為 null（舊版或未印分類的版面）而沒比對到，一律無法判定，不輸出未見——舊版查封可能以代碼表以外的自由文字印出。
    - 依 5 份樣本逐張推算（限制登記、信託相同）：長春路、懷寧街第 1 張（00312-000）→ 未見（建號全部、標示部與所有權部其他登記事項皆空白）；懷寧街第 2、3 張、竹田鄉 2 張 → 無法判定（有無類別前綴的其他登記事項）；杭州南路 3 張、忠孝東路 2 張 → 無法判定（所有權個人全部）。
  - **不輸出「無」**：「未見」只表示這份謄本上沒印；要說「法律上沒有」需地政事務所確認。（jgb2 `6c4da96339` 的教訓：說「無」講錯會直接改變判斷。）
  - 判定所依的代碼表項目以資料檔放在 repo（`transcript_records_codes.json`：每項記代碼表編號、代碼、原文、來源網址、版本 115/08），不散寫在程式裡；代碼表是地政司公開的全國資料，不是針對特定謄本的補丁。
- **建構方式**：輸入只用 `parse_with_ledger` 已分好的張／部／筆與「標籤:值」，依「部＋原文標籤（去空白）」放進固定鍵；值要再拆的衍生鍵只用上表「衍生鍵的取值規則」，不重讀原文、不改 G6 解析器。新舊版同義標籤（謄本檢查號／謄本種類碼）以 `transcript_records_codes.json` 歸一，列來源。
